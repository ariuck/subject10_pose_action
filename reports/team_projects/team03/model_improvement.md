# 3팀 동작 인식 모델 성능 개선 기록

무인 상점 이상행동 17개를 스켈레톤(YOLO11n-pose, COCO 17 관절)과 Random Forest로 분류하는 모델을
어떤 순서로, 왜, 얼마나 개선했는지 정리했다. 효과가 없었던 시도도 함께 적었다.

모델 설정은 모든 단계에서 같다: Random Forest 300 Tree, class_weight balanced, random_state 42, 영상 1개를 30 Step Sequence로 맞춤.

```text
① 교재 38-D           관절 좌표 34 + 관절각도 4
② 팀 Feature 45-D      + 상체 기울기 · BBox 비율 · 골반-바닥 높이 · 양발목·양손목 속도
③ 측면 좌우 반전 증강   측면(T02) Keypoint를 뒤집어 학습 데이터에 추가
④ 후면 Take 추가       정면(T01) · 측면(T02)에 후면(T03) 촬영 85개 추가
⑤ 5명 교차 평가        사람 한 명으로 낸 점수가 흔들려서, 5명을 한 번씩 Test로 빼 평균
```

## 데이터

| 항목 | 내용 |
|---|---|
| 사람 | 5명 (S01~S05, 실명 대신 가명 ID) |
| 동작 | 17개 이상행동 (`configs/team03_action_classes.csv`) |
| 촬영 방향 (Take) | T01 정면 / T02 측면 / T03 후면 (④에서 추가) |
| 영상 | 170개 → 255개 (5명 × 17동작 × 3방향) |
| Frame | 70,159 → 98,524 (Pose 성공 99.7%) |

## 단계별 결과 (한 사람 Validation · Test)

처음에는 Train S01~S03 / Validation S04 / Test S05로 고정해 평가했다.

| 단계 | Train 구성 (사람당 동작마다) | Validation | Test | 비고 |
|---|---|---:|---:|---|
| ① 38-D | 정면 + 측면 = 2개 | 0.618 (21/34) | 0.588 (20/34) | 교재 기준 |
| ② 45-D | 정면 + 측면 = 2개 | 0.735 (25/34) | 0.647 (22/34) | 오답 13 → 9 |
| ③ 45-D + 측면 반전 | 정면 + 측면 + 측면 반전 = 3개 | 0.824 (28/34) | 0.647 (22/34) | Validation만 상승 |
| ④ 45-D + 후면 | 정면 + 측면 + 후면 = 3개 | 0.784 (40/51) | 0.667 (34/51) | 평가에 후면 포함 |
| ④ 45-D + 후면 + 측면 반전 | 정면 + 측면 + 측면 반전 + 후면 = **4개** | 0.706 (36/51) | **0.765 (39/51)** | Test 최고 |

- ①~③은 정면·측면 34개, ④는 후면까지 51개로 평가했다.
- ④에서 Validation과 Test가 반대로 움직였다. Validation으로는 "후면만 추가"가, Test로는 "후면 + 반전"이 좋았다.
- 사람 한 명으로 낸 점수는 사람에 따라 크게 흔들린다. 팀에서 사람 번호를 다시 정했을 때도 같은 방법의 Test가 0.765 → 0.647로 바뀌었다. 그래서 ⑤ 교차 평가로 결론을 냈다.

## ⑤ 5명 교차 평가 (Leave-One-Subject-Out)

반전 Clip은 Train 사람 것만 넣는다. 설정을 고르는 단계가 없어서 Validation은 따로 두지 않았다.

## 시도별 해석

### ② 팀 Feature 45-D — 효과 있음
- 교재 38-D는 관절 위치와 각도만 본다. 3팀 동작은 눕기·쓰러짐(몸이 수평인지)과 차기·던지기(얼마나 빠른지)가 핵심이라 정보가 부족했다.
- 상체 기울기·BBox 비율·골반-바닥 높이로 자세를, 0.1초 간격 발목·손목 속도로 움직임 세기를 넣었다.
- 교차 평가에서도 모든 구성에서 45-D가 38-D보다 7~10%p 높았다.

### ③ 측면 좌우 반전 증강 — 평균 효과는 없음, 확신도는 오름
- 측면은 카메라 한 대로 한쪽에서만 찍었다. 매장 카메라가 반대쪽에 있으면 사람이 거울처럼 보이므로, 측면 Keypoint를 뒤집어 반대 방향 데이터를 만들었다.
- 방법: x 좌표 반전(`x_px → 너비 − x_px`, `x_norm → 1 − x_norm`) + 왼쪽·오른쪽 관절 이름 교환 + BBox 반전. 영상은 다시 Pose 추론하지 않았다.
- 반전이 맞는지 Feature로 확인했다. 정규화 x 부호, 좌우 관절, 좌우 각도·속도가 서로 바뀌고 상체 기울기·BBox 비율·골반 높이는 그대로였다.
- 교차 평가 평균은 0.761 → 0.753으로 차이가 표준편차(약 0.05)보다 훨씬 작다. 정면·측면은 조금 오르고 후면은 조금 떨어졌다.
- 평균 Confidence는 0.303 → 0.325로 올랐다. 학습 데이터가 늘어 나무들의 표가 덜 갈라졌다. 실시간 인식에서 Threshold를 넘는 예측이 늘어나는 쪽이다.
- 원본 모델도 반전된 측면을 원본 측면과 비슷하게 맞혔다. 지금 데이터에서는 카메라 방향보다 사람 차이가 더 크다.

### ④ 후면 Take 추가 — 가장 큰 효과
- 정면·측면만 배운 모델은 후면 영상을 28%밖에 못 맞혔다. 한 번도 본 적 없는 방향이기 때문이다.
- 후면 85개를 추가하자 후면 정확도가 0.28 → 0.77로 올랐다. 전체 평균도 0.635 → 0.761 (+12.6%p)로 다섯 사람 모두 올랐다.
- 대신 정면 정확도는 0.847 → 0.765로 떨어졌다. 학습 데이터에 후면이 섞이면서 정면에만 맞춰진 판단이 약해졌다. 카메라가 정면에만 있다면 정면+측면 모델이 더 나을 수도 있다.
- 후면 85개 QA: 자동 QA 84개 AUTO_PASS, 1개 CHECK(S03 후면 휘두르기 — 몸 앞쪽 팔이 몸에 가려져 팔 Confidence가 낮음). 사람별 확인 사진으로 85개 모두 동작 수행과 전신 포함을 확인해 PASS로 판정했다.

### ⑤ 교차 평가 — 결론을 바꿈
- 한 사람 Test에서는 "후면 + 반전"이 0.765로 가장 좋아 보였지만, 5명 평균으로는 "후면만 추가"와 같은 수준이었다.
- 사람마다 결과가 달라서(S01은 반전 후 −4%p, S05는 +4%p) 한 사람 점수로 증강 효과를 판단하면 안 된다는 것을 확인했다.

## 최종 선택

| 항목 | 내용 |
|---|---|
| Feature | 45-D (교재 38-D + 팀 Feature 7) |
| Train 구성 | 사람·동작마다 4개: 정면 T01 + 측면 T02 + 측면 반전 + 후면 T03 |
| 예상 성능 | 처음 보는 사람 기준 Accuracy 약 0.75 (5명 평균 0.753, 범위 0.686~0.824) |
| 선택 이유 | 교차 평가 정확도는 "후면만 추가"와 같은 수준이고, Confidence가 가장 높다. 실시간 서비스에서 확신 있는 예측이 더 많이 나오고, 측면 카메라가 반대쪽에 있는 경우도 대비할 수 있다. |

| 비교용 모델 | `artifacts/team03/day06/team_45d_3view_hflip/` (S01~S03으로만 학습, 한 사람 Validation·Test용) |

## 아직 남은 개선 후보

- 밀치기 ↔ 잡고 흔들기 ↔ 샷건처럼 팔로 하는 동작끼리의 혼동은 Pose만으로 풀리지 않았다. 물체 위치(ROI) 정보가 필요하다.
- 정상행동(물건 고르기·걷기) 영상이 없어 "정상 vs 이상"은 아직 판단할 수 없다.
- 시간 순서를 직접 다루는 모델(LSTM·1D-CNN)과는 아직 비교하지 않았다.
