# 3팀 17개 동작 영상 데이터 정리 (5명 × 34개 = 170개)

## 1. 데이터

- 출처: 3팀 드라이브 `교과10 동작 영상` 폴더 (모션캡처 촬영 때 팀원이 직접 찍은 영상)
- 사람: 강동연(P1), 김동훈(P2), 김석범(P3), 이후영(P4), 지혜성(P5) — 손상우 폴더는 비어 있어 제외
- 사람마다 17개 동작 × 정면·측면 = 34개, 모두 170개 (약 4.9GB)
- 저장 위치: `data/team3_videos/<이름>/` (Git 제외)
- 약 60fps, 세로 1080×1920 145개 / 가로 1920×1080 25개
- 강동연은 11/16, 나머지 4명은 11/13 촬영

## 2. 라벨표 — `configs/team3_all_actions.csv`

- 사람별 파일을 시간순으로 2개씩 묶으면 1~17번 동작 순서와 같다 (팀원 확인).
- 각 쌍은 앞 파일이 정면, 뒤 파일이 측면이다.
- 예외: 김석범·지혜성 9번(앞으로 누워서 폰보기)은 측면을 먼저 찍었다. 영상별 대표 장면에서 세로(머리 쪽) / 가로(몸 옆) 화면으로 확인했다.
- `sample_id` = `사람_동작_방향` (예: `P3_A09_side`)
- 만드는 코드: `scripts/team3/team_build_label_table.py`
- 검사: 170줄, 중복 없음, 파일 모두 존재, 사람마다 정면 17 / 측면 17

## 4. 동작 시작·끝 구간 — `configs/team3_action_segments.csv`

영상과 Sequence는 자르지 않고, 시작·끝 시점만 따로 기록했다 (실패 Frame을 지우지 않는 것과 같은 원리).

계산 방법 (`scripts/team3/team_action_segments.py`)

1. 정규화 좌표를 Pixel 좌표로 되돌린다: `좌표 × shoulder_width + hip_center`
2. 몸 관절 12개(어깨·팔꿈치·손목·골반·무릎·발목)가 0.1초 동안 움직인 평균 거리를 구한다. 60fps에서 바로 앞 Frame과 비교하면 좌표 떨림이 크게 잡혀서 0.1초 간격을 썼다.
3. 상체 길이(어깨 중심~골반 중심) 중앙값으로 나눠 사람 크기 차이를 없앤다. 측면에서 불안정한 어깨 폭 대신 상체 길이를 썼다.
4. 0.5초 이동 평균으로 부드럽게 한 뒤, 영상마다 `하위 5% + (상위 95% − 하위 5%) × 0.2`를 기준값으로 정한다.
5. 기준값을 0.15초 이상 넘은 첫 시점이 시작, 마지막 시점이 끝이다. 앞뒤로 0.2초 여유를 둔다.

결과 (170개)

| 항목 | 중앙값 | 범위 |
|---|---|---|
| 앞에서 뺀 시간 | 0.57초 | 0~5.2초 |
| 뒤에서 뺀 시간 | 0.11초 | 0~1.1초 |
| 동작 구간 길이 | 4.6초 | 1.9~25.0초 |
| 전체 대비 동작 구간 | 87% | 52~100% |

확인

- 영상마다 [처음 / 시작 / 가운데 / 끝 / 마지막] 장면과 움직임 그래프를 한 줄로 모아 확인했다 (`reports/team3_videos/segments/P*_segments_*.jpg`, `scripts/team3/team_segment_check_images.py`).
- 시작 장면은 동작 직전에 서 있는 모습, 끝 장면은 원래 자세로 돌아온 모습으로 잡혔다.
- 앞부분을 많이 뺀 영상(김석범 2번 측면 2.5초, 이후영 10번 정면 5.2초, 이후영 16번 정면 3.0초, 지혜성 15번 정면·측면 3.8·3.4초)도 앞부분은 가만히 서 있는 장면이었다.

한계

- 누워 있거나 앉아 있는 동안처럼 움직임이 적은 시간은 시작~끝 사이에 그대로 들어간다. 눕기·기절 같은 동작은 이 정지 상태도 동작의 일부라서 일부러 포함했다.
- 끝 구간에는 동작 후 다시 일어나 원래 자세로 돌아오는 시간도 들어 있다. 동작 핵심 부분만 따로 쓰려면 구간을 더 나눠야 한다.
- 지혜성 16번 측면처럼 누운 채 녹화가 끝난 영상은 끝 = 영상 마지막이다.
